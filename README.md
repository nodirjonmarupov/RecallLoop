# RecallLoop

RecallLoop is a learning and spaced-repetition system that helps users review learned topics at the right time.

## Core Features

- Organize learned topics.
- Schedule automatic reviews after 1, 3, 7, and 30 days.
- Track review progress.
- Expand later with AI-powered explanations and quizzes.

## Tech Stack

- Python 3.13
- FastAPI
- PostgreSQL
- Pytest
- Ruff
